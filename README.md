## 👋 소개

- **PetPalace**에서 예약 API와 PostgreSQL 데이터베이스를 설계하고 Toss Payments 결제를 연동했습니다.
- **CGI_MOA**에서 Bruno로 GET·POST API의 요청과 응답을 검증했습니다.
- **자동차 번호판 인식 시스템**에서 YOLO 모델 학습과 번호판 검출, PySide6 모니터링 화면 개발을 담당했습니다.
